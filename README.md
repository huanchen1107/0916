# Huan Chen (陳煥) - AIoT 2026 Personal Page

A modern cyberpunk dark glassmorphic personal page featuring a live real-time digital clock, dynamic context-aware greetings, and AIoT 2026 focus highlights.

🔗 **Live Demo**: [https://huanchen1107.github.io/0916/](https://huanchen1107.github.io/0916/)


## 🚀 Features

- **Live Real-Time Digital Clock**: Millisecond-accurate clock with live seconds, 12H/24H toggle, full localized calendar date, timezone display, and daily elapsed progress bar.
- **Dynamic Greeting**: Automatically greets the visitor according to local time (Morning, Afternoon, Evening, Night).
- **Aesthetic**: Cyberpunk dark mode with glassmorphic cards (`backdrop-filter: blur`), glowing neon ambient aura, and interactive HTML5 particle canvas background.
- **AIoT 2026 Focus**: Interactive technical stack tags, research focus pillars, and simulated embedded node diagnostics.
- **Customizable**: In-page edit modal with persistent `localStorage` support.

## 🛠️ Tech Stack

- **HTML5**: Semantic document layout & accessibility.
- **Vanilla CSS3**: Cyberpunk glassmorphism, responsive grid & flexbox, keyframe animations.
- **Vanilla JavaScript**: Real-time clock loop, canvas particle physics, local storage manager.

## 📦 How to Run

1. Simply open `index.html` in any modern web browser.
2. Or serve with any static web server:
   ```bash
   python -m http.server 5173
   ```
   Then open `http://localhost:5173`.
